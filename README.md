A one-line review of the most boring object in the office: the paperclip. It held a whole career together for three years, never got promoted, and still bent under less pressure than its reviewer. The program builds the review from named parts, validates it against the one-line gate (single line, character and word-count budgets, rating present), and prints exactly that one line — deterministically, every run.

## Run it

```sh
node main.ts
```
